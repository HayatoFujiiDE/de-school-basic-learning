# 第5学年の操作図・段階解説

追加モジュールだけで24操作図と6段階解説を登録する。既存コードと重複したら登録前に拒否し、4年の定義と描画関数を変更しない。追加スクリプトの二重読込は無作用。操作図の状態は既存の単元identity・mounted・整数範囲・列挙値検査を通す。小数のつまみは整数の個数で表し、浮動小数のstep判定を使わない。

`visuals-grade5.js` は `BL.visuals.definitions` へ `draw(state)` を登録する。図の文字と補足HTMLはescapeを通し、外部入力のHTMLは使わない。`lesson-scenes-grade5.js` は既存itemsへ追記し、完全一致する6コードのみ自分の描画器へ振り分ける。他コードは元のrenderへ渡す。共通playerのSVG許可リスト、review gate、再生停止とcleanupをそのまま使う。自作のverified記録は作らない。

## 検証方針

全操作状態の数値整合と、全scene各stepのphase0..1を細かく検査する。特に平均の矩形の正面積交差、分数の色面積、三角形の面積・辺長、割合の総数と色数を測る。末端だけの検査で途中の重なりを見落とさない。

実ブラウザは共通UIと実教材が統合されたfile://を最終検査対象とする。390/1024/1440、両mode、文字bboxのviewBox内包含、文字同士の交差、操作部品の到達、tryIt、段階往復、cleanupを確認する。制作時の純描画ハーネスは素材の検査だけであり、最終統合の代用ではない。
