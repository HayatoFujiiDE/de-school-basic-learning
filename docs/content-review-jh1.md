## レビューで直した点

| 検出した不足 | 修正と根拠 |
|---|---|
| 正確な値を近似と表現 | `−1/2＝−0.5` を等しい値として記述。素因数分解では25を5×5へ分ける対象を明確化 |
| 反例の説明 | 一つの反例は「いつでも整数になる」という主張を否定する、と説明を修正 |
| 単問の条件が前問に依存 | 品の代金、同半径の弧の中心、対応点A′/B′、表裏だけの結果などを該当問題内へ再掲 |
| 方程式・比例式の除法条件 | 同値変形の倍率や比例式の分母が0でないことを短文と問題でも明記 |
| 比例のグラフの変域 | 数直線上の全ての数を使う場合の直線と、整数個数の点・表示窓を区別。連続な区間だけでは原点を含む保証がないため条件を補足 |
| 個数と組数 | 品の個数は0以上、等分する組数は正。割れない品は60の約数に限定。`y/n` は `n＞0` の範囲で用いる |
| 移動・作図の条件 | 軸上の固定点を区別。平行移動の対応線分が同一直線上になる場合も含め「同じ向きで長さが等しい」と記述。弧が交わるコンパス幅、元点と対応点、回転の中心・向き・角度を明確化 |
| 90°回転の向き | 実装の `(x,y)→(−y,x)` は反時計回り。claimと操作名へその向きを追記し、図の座標は維持 |
| 接線の向き | 接点が変わると必ず異なる向きになるとは言わず、接点の半径に垂直となる性質を記述 |
| 二平面の位置関係 | 平行と交線、直方体の向かい合う面と隣り合う面を本文へ追加 |
| 立体を作る移動 | 面に垂直な方向への移動を指定。面内の移動まで柱体を作ると解釈させない |
| 扇形の外周 | `0＜θ＜360` の半径二本と、360°の円周だけの場合を区別。長さは `(2π＋6)cm` と括る |
| 統計の分母と順序 | 相対度数の総度数を正とし、「階級が小さい順」を明示。範囲と累積度数のコードを実際に扱う単元へ限定 |
| 用語・記号の対応 | 符号、項、係数、変数、弧、弦、∠、△、∥（//）、⊥に定義や用例を追加。単にコードを付けるだけの対応を除去 |
| 計算順の文言 | 数学的な意味を保って「括弧、累乗、乗除、加減」「乗除どうし・加減どうしは左から」と具体化 |

制作中の表示IDも別に検出された。作者の全状態走査で直方体の呼出しキー未指定に由来するID12件を検出し、明示キー追加後は12→0、ID以外の幾何出力は同じというA/B結果が報告された。独立側は該当ソースと報告を確認した。公開前の検出・修正であり、実利用者の操作障害を観測したとは記録しない。

## 実行した検査

作者の最終原稿と資料、統合側の104コードregistry、独立reviewファイルだけを一時検証用フォルダに組み合わせて、`tools/check-jh1.cjs` を実行した。製品ファイルは変更していない。

```text
JH1_INDEPENDENT_MATH=PASS units=38 questions=304 games=38 claims=732 numeric_recomputed=155 official_rows=107 terminal_coverage=69
JH1_POSITIVE_PROBES=PASS wrong_answer changed_prose missing_unit missing_jh1_script missing_grade6_script same_count_substitution old66_runtime_mutation source_wrapper_mutation invalid_expression
JH1_SOURCE_SHA256=d2893eea2e2741776e3db58691f5767d6eeaaaef749cff04eca35910f7a02c1b
JH1_EVIDENCE_LIMIT=math_and_text_review_not_operator_publication_approval
```

旧小学4・5・6年の3原稿はバイトハッシュを固定し、組立後も旧66単元・513問、旧カテゴリ・出典を比較した。期待コードはレビュー側の38件と旧66件の完全一致で判定し、registryの並び順には依存しない。欠落スクリプト、同数の別コードへの置換、誤答、説明の変更、旧単元の変更、ソース本体への追加はそれぞれ陽性対照で拒否した。

保存移行の独立検査は `tools/check-jh1-migration.cjs` に分離した。合成保存データのみで15,658チェックを実施し、旧2→3・2→4・3→4・4→4、2/3/4→5・5→5、読取専用保全、学校段階の区別、負号正規化と入力言語の境界を確認した。教材原稿の承認と保存移行の承認は別に扱う。

動画2本は `sources/media-jh1-manifest.json` と `tools/check-jh1-media.cjs` に独立記録を置いた。実画像を見て字幕・条件を確認し、全1,290フレームのデコード、600フレームの固定原点と移動点、690フレームの式の札12→6→3を検査した。動画は20秒と23秒、1280×720 H.264、音声なし。

## 限界

コードへの対応は、例・説明・練習が該当することを示す。年間授業の全て、全ての応用問題、児童生徒の理解や到達を保証するものではない。数学的活動のコードも、教材に問いと説明の機会があることを指し、実際に対話が行われたことの証明ではない。

ハッシュ検査は、読了した内容を保つための回帰検査であり、将来変更された文章を自動で数学的に承認する仕組みではない。本文・問題・claim・対応コードの変更時は差分の再読と独立期待値の見直しが必要となる。
