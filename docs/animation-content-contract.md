# 単元の中身に置く動く図解・動画

対象は、動きが考え方の理解を助ける8箇所。全20単元には従来の操作図がある。動画を全単元へ機械的に付けず、選んだ内容で「予想する→変化を見る→途中を戻る→自分で図を変える」をつなぐ。既存の学習指導要領コードを素材のキーとして使う。

## 素材と根拠

- `js/lesson-scenes.js`: `BL.lessonScenes.items[code]` の題名・問い・4〜5段階の文・予想問題・既存操作図への状態。`claimIds` は `js/units.js` の同じ単元の確認済み主張。`render(code,step,phase)` は局所SVGを返し、0〜1のphaseが途中の変化を示す。
- `sources/lesson-review.json`: 制作者とは別の担当による数、等分、面積、角度、辺、縮尺、claimsの確認。素材ファイルのSHA-256を固定する。
- `sources/media-manifest.json`: 独自動画4本の制作ソースhash、動画hash、秒数、字幕全文、主張ID、根拠の確認状況。
- `js/lesson-review.js`: 上の独立確認を通した項目だけを `tools/export-lesson-assets.cjs` で書き出す。未確認の項目は画面に出ない。公開承認ではなく、制作プレビューで使う根拠確認である。
- `assets/lessons/<code>.svg` と `.mp4`: 端末内の画像と動画。外部の動画サイト、埋め込みiframe、トラッカーは使わない。

計算や図の不変条件は、各単元のclaimsとadapt-rulesに従う。今回、小数の交換 `5.00 = 4 + 0.9 + 0.10` は導出を省略せず `motion1` として明記した。教材版は2へ更新し、過去の正誤・説明確認を持ち越さない。

## 操作

対象単元の冒頭「動く解説へ」から本文の例へ移動できる。予想に答えなくても図を見ることができる。図は「動きを見る」でのみ再生し、停止、前、次、はじめからを選べる。段階の文字説明と全文も読める。予想と図の操作は達成率に含めず、回答は永続保存しない。

動きを減らすOS設定では連続再生を使わず「前へ」「次へ」の静止図で説明する。画面遷移、表示切替、ページ非表示では再生を止める。動画と図の同時再生はしない。SVGは要素/属性を許可リストで検査し、任意スクリプト、イベント属性、外部URLを入れない。

動画は字幕付き・音声なしの20〜27秒。本人が標準controlsで再生、停止、早送りする。閲覧用アプリにManimやPythonは不要。動画の読み込みは本人が開いた時だけ（preload=none）。文字で同じ内容を読める。

既存操作図へ渡す値は既知field・数値範囲・刻み・列挙値の完全一致で検証し、一部だけ適用しない。同じ例を再現できる角度250°/正方形5個と、異なる数や単位で試す分数・小数・折れ線などをボタンの文で区別する。

## 制作

Manim Community 0.20.1（開発時のみ）で独自の4場面を生成した。第三者Skillの配布元・記載内容と公式仕様の照合、実行環境・依存の確認範囲は [skill-safety-review.md](skill-safety-review.md)。新しいパッケージ、音声API、クラウド実行は追加していない。更新照会を止め、ネットワーク監査hookでsocket接続を拒否し、プラグインなし・ローカル日本語フォントで描画する。

既存Manim 0.20.1が利用可能なPythonで `python tools/render-media.py`（最大4本、有限処理）。特定の1本は `--only 8250243250000000`。版とフォントを検査し、不一致ならインストールせず止まる。再生成後は動画とsourceのhashが変わり得るため、独立確認とmanifest更新、`sh tools/check.sh` が必要。公開用デプロイは含まない。

可読性の検査では図/式/字幕の領域を分離し、描画時の実テキストbboxと切り取った片/寸法ラベルの交差をassertする。元の重なりを検出する陽性対照と、修正版の実動画フレームで確認する。レンダー成功だけを教材の確認完了とは扱わない。
