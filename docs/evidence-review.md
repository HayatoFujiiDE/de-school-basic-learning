独立数学検査は制作側の答えから期待値をコピーせず、問題文から別に求めた期待解答と根拠を `tools/math-review-expectations.json` に保存した。誤答へ変更したコピーと、説明を変更したコピーが拒否される対照実験を内蔵している。

操作図の検査は実 `visuals.js` をNode VMで読み、実 `render` と `bind` を通した。全スライダー値、複数スライダーの全組合せ、全選択肢、そろばん各桁0〜9を検査した。表示式に加え、マス・箱・珠の個数、平行/等辺を表す座標、角の方向・長さ、グラフの点と尺度を確認した。分配法則の表示結果だけを `n×7` から `n×8` に変えた一時コピーは exit 1 で拒否された。

再現コマンド（統合後）:

```sh
node tools/check-math.cjs
node tools/check-visuals.cjs
```

これらはブラウザのレイアウト・アクセシビリティ・永続化の検査とは別。ブラウザ上の実表示は統合担当の検証記録を参照する。

## カリキュラム対応と限界

独立取得した138行と `coverage-map.json` の code/text/Excel row を全照合。127行が教材に対応し、11行は見出しとして区別されている。16の内容項目（A8/B5/C2/D1）、知識技能・思考判断表現の細目49件、内容取扱い10件に未対応コードはない。`8250245A00000000` は英字Aを含む正式な16文字コードである。

これは「コードの全対応」と「内容に触れる入口がある」ことの確認である。次の技能の完了は、このプレビューの自動判定だけでは確認できない。

- 筆算を自分で書く、実物のそろばんで加減する、紙に作図する、分度器を実際に合わせて測るなどの身体的操作。画面のそろばんは各桁の数字を変える表示モデルで、実物の全加減操作を自動評価しない。
- 紙の図形を敷き詰める、展開図を組み立てる、目的に合わせて資料を集めてグラフを作る活動。説明・問い・操作図はあるが、活動の遂行を全面的には観測しない。
- バディへの説明の意味的な正しさ、学習態度、実際の児童の理解。確認点と自己確認の仕組みであり、AIや人が説明を採点したとの表示はしない。
- 児童本人による使用試験や教員・運営の公開審査は未実施。この独立数学確認を人の公開承認へ読み替えない。

## レビュー中に反映した点

- そろばんに億・兆・百分の一の位の説明と設問を追加し、操作図も0.01までの5桁へ拡張。
- 1問ずつの画面で参照が途切れる「同じカード」「上の箱」等に、必要なデータ・条件を再掲。
- 2桁除法の代表主キーを除法全体の `8250243130000000` に変更。除法の性質 `8250243131400000` は対応コードとして維持。
- 出典の第4学年ページ範囲を印刷pp.179–231に訂正。
- そろばんの操作ラベルを「珠を一つ動かす」ではなく「その位の数を1増減」に合わせ、0°と360°の操作図を区別。
- 操作例と説明・練習で数値が異なることを明示。

観測と原因を混同しないため、誤り例や別の数値例は意図された教材表現として確認し、コード抽出は独立XML読取りで照合し、数式は手計算と実コード表示を照合した。計器の誤り・呼び出し経路の未確認を除くため、正しい状態の通過と故意の誤りの拒否を両方実行した。これらの実行結果から児童の理解や学習効果の因果は推定していない。
