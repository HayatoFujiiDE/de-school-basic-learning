# 中学2年数学の教材設計・出典記録

## 追加範囲と保存境界

内部学年8を中学校第2学年・数学として扱う。公式prefixは835022。39単元、各8問で312問、予想を確かめるゲーム39件。A数と式12、C関数7、B図形13、Dデータの活用7の順に構成する。各単元に小学生向け/中学生向けの短文・詳細の4説明、異なる関心カテゴリ2入口、4段階の例題、誤解と訂正、ヒント付き問題、バディ1件の問い・追問・確認項目・回答例、claimsとadapt-rulesを備える。

`units-jh2.js`は既存version5・104単元の後へ39件を追加してversion6・grades[4,5,6,7,8]とする。前提が欠ける場合と二重読込では追加せず、共通coreの全カタログ照合へ判断を委ねる。既存4原稿のbytes、旧104unitの内容とオブジェクト参照、旧sourcesとcategoriesを保持する。小学・中1抽出器や共通UIは本変更の対象外。

file://、ES2017、非moduleの通常scriptで動き、fetch・外部runtime・式評価器を追加しない。分数や文字式の答えは選択式、または指定された分母に対する分子などの数値で答える。数字入力へ文字式の評価器を持ち込まない。順序問題は操作の依存関係がある2問だけで、独立した証明根拠の並びを唯一の解として強制しない。

作者版は全件review.evidence=pending、publication=preview、humanApproval=null。claimのverifiedは出典・作者検算を付した主張の状態であり、unitの独立承認とは別。独立担当の全件照合後、統合担当がunit.review.evidenceだけを昇格する。公開許可は別の承認記録に従う。追加後は143単元、練習1129問になる。

## 数学の境界と図・動画の契約

全39操作図の460合法状態を、同じunitのclaim id `visual`に数値・一般則・変数範囲として記録した。8段階解説は各4段、合計32段で`motion`、2本の動画は`video`のclaimを別に持つ。参照されない別claimだけに描画の数学を置かず、それぞれのclaim単体へ必要条件を含める。対応例は、同類項、奇数の和、加減法、切片と傾き、平行線の角、合同証明、箱ひげ図、二硬貨の樹形図。図・scene・動画のブラウザ表示検証は各所有担当と統合担当の実測に基づく。

- 文字式：0でない式の次数を扱い、0の式の次数は範囲外。単項式の除法は除式0を除外。負の係数・整数の図は式札で表し、負の実物の個数へ置換しない。
- 連立：和3x=9だけでは元の二式と同じ条件ではない。元の一方x−y=2を保持し、x=3,y=1を両元式へ検算する。加減法の図・scene・videoは同例で一致。
- 関数：一次関数はy=ax+b,a≠0。a=0は一定関数の比較。変化の割合はΔx≠0、y/xを使う比較はx≠0。全数の直線と場面の区間/整数入力を分ける。縦線x=kはyをxの関数にしない。
- 図形：非退化と頂点の対応、内側/外側・同位角/錯角の位置を明記。三角形の合同の未証明結論を仮定へ戻さない。DがBCを二分する箇所では線分内部/中点を明記し、単なる三点の共線と区別する。四角形の十分条件は同じ一組/二組の範囲を保つ。
- 四分位数：2個以上を対象に、昇順にし奇数個の全体中央値を上下から除く方法を固定。実図は8個/9個。ひげは最小/最大で外れ値除外方式を混ぜない。幅0、等しい値の重なり、同じ五数でも元データが違う例を扱う。
- 確率：数えた基本結果の等確率、二硬貨/二さいころの区別と独立、抽選盤の角度一様、袋の各玉の等確率を局所の説明へ明記。有限回の比率一致や次回の結果を保証しない。戻す/戻さない場合を分け、少なくとも一方の余事象を両方とも該当しない場合として数える。


作者の数値102回答は、別に記述した算術式を安全なAST解釈とPython Fractionで厳密再計算した。許可する式は定数・単項符号・四則・剰余・非負整数累乗で、任意関数呼出は扱わない。意味や選択肢の唯一性を独立担当が原稿から全件読んで確認する手続きとは別であり、作者ledgerから独立期待値を生成しない。

独立レビューで、短文の0条件、単問の前提、対頂角の内外位置、線分内部の条件、等価な別選択肢などを精密化した。全て生成claimへ同期し、数値を式で確かめながら、正答だけでなく誤選択肢の妥当性も確認した。最終独立fixtureとverified化は別担当の所有。

制作batch中に、未出力の『頂点数』がliteral禁止語『点数』へ一致し、書出前のgateが停止した。元語REJECT、新語『頂点の数』PASSの実対照と独立意味確認の後、原稿だけを変更した。禁止リストや照合方法は緩めず、保存済み原稿・既存教材・公開物への影響はない。中央の既存同分類recordへの追記案を統合担当へ渡す。memoryへの追記は行わない。

本文・coverage・claimsを変更した場合は独立差分確認を要する。review.evidenceだけの承認変更ではclaims-indexやnumeric-auditの内容を変更する必要はないが、独立fixtureのsource hashは承認版へ更新する。保存版6からの復旧は共通計画に従い、旧版への書戻し投影で新学年の保存内容を落とさない。
