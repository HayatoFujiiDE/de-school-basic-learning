# 動く例題の設計と確認

`js/lesson-scenes.js` は8単元の図と予想問題を提供する。契約は [動く図解の契約](animation-content-contract.md)。既存の教材・正答・達成率は変更しない。公開や根拠確認の状態もここでは付与しない。

すべての図は600×400のSVG。白紙・緑・オリーブを使い、色の意味は文や位置でも示す。外部画像、装飾、通信、アニメーションAPIを含まない。`render(code, step, phase)` は決定的で副作用がなく、phase 0は直前の配置、1は選んだ段階の配置を表す。step 0は常に初期状態。未知コード・不正な段階・非有限phaseは空文字、有限phaseは0〜1に制限する。テキストはXMLエスケープする。再生、停止、読み上げ用の段階説明、予想問題の回答、画面のライフサイクルは `lessons.js` が担当する。

## 検査

最終の局所検査では全33段階×phase 0/0.25/0.5/0.75/1＝165フレームを生成し、ES2017、XMLパース、決定性、参照claims、選択肢と答え、NaN/Infinity/undefined不在、禁止要素不在を確認した。数の保存は小数500セル・除法9百/24一・分数6枚・面積48マスの実出力要素数で確認した。

Chromeで390px幅のカードに表示した最終8場面と途中8場面を目視し、SVGの全テキストのgetBBoxがviewBox内に収まることを確認した。生成物は検査用の `/private/tmp/basic-scene-audit/` に置き、納品ファイルへ含めない。最終統合後の独立根拠検証とUIの再生・停止検査は統合担当が実行する。

実出力: `SCENE_JS=PASS ES2017=PASS deterministicFrames=165 units=8 TRANSFER_STATES=PASS`、`SVG_XML=PASS frames=165 CONSERVED_CELLS=PASS`。Chromeの390pxカード検査は `outOfViewBox: []`。

追加レビュー: 小数の明示的な分解は独立検証担当が追加する `motion1` も参照する。図全体の式はbaseline 380、小数の取り分けラベルは330へ配置し、角度270°目盛りと式、小数の取り分けラベルと式の領域を分離した。
