## 1. Goal

## 6. Chosen approach
学年別ファイル追加方式。A22→C6→B15→D4。代表主キー47件は全て公式に実在し、全92原文との多対多対応と54終端の網羅を記録する。8解説は因数分解・平方根近似・平方完成・放物線・相似の体積比・円周角・三平方・標本推定。動画はx²+5x+6=(x+2)(x+3)と3–4–5の三平方。
無作為抽出は8350233411200000だけに限定したbind拡張で、既存setStateを呼ぶ。架空部品8個から3個の56組を辞書順に列挙し、表示は1〜56、既定1。固定例と実抽出を区別する。Uint32Arrayの1値をcrypto.getRandomValuesで取得し、4294967264未満のみ採用、値%56+1で選ぶ。最大8回、同一標本の再抽出は正常。生成値を永続化・送信しない。
実抽出後の手動変更・リセットでは固定例の表示へ戻す。setStateが対象や配置の検査でfalseを返した場合は、成功表示・focus移動を行わない。三平方の解説は二つの固定配置の合同対応を示し、標本推定は母集団の真の該当数が既知であるかのように着色しない。

## 7. Rejected alternatives
共通renderer/schemaの全面再設計は旧143図・36段階解説・保存境界への影響が過大。別アプリはUI/保存保護を二重化し進捗を分断する。固定例だけを無作為抽出と呼ぶ案は採用しない。実抽出は新モジュール内で閉じ、共通APIを増やさない。

## 8. Risks and failure matrix
| 状態・失敗点 | 次の動作と有限な結末 | 保存への影響 |
|---|---|---|
| 正常な版2〜6 | 元版に存在した学年だけ再採点して移行 | 旧回答・buddyを保持 |
| script欠落/同数置換/重複/版矛盾 | ready=false、教材欠落案内 | 書込/削除0回 |
| pending/invalid本文 | verifiedだけ表示、readonly | 元文字列を保持 |
| 未来版/破損/読取拒否 | readonly案内 | save/resetで保護を解除しない |
| 書込拒否 | 保存失敗を表示、自動再試行なし | 書込前の値を保持 |
| random APIなし/例外 | 可視案内、操作前の状態を維持 | 永続書込なし |
| random値が拒否域 | 最大8回、全拒否なら可視案内して終了 | state更新前なので値不変 |
| random正常/同じ標本 | 全56組から1組を表示、再描画後にボタンへfocus | 達成率・保存を変更しない |
| bindの重複/別単元への再bind | 追加listenerを重複登録せず、別単元では解除 | 保存なし |
| rollback | 中3入口を停止、版7coreと全データを維持 | 新旧の記録を保持 |
数学条件は根号の非負性と平方根±、非零の除数、二次方程式の全解と文脈制限、a≠0と変域、対応順/正の相似比、円周角の同じ弧と逆の同じ側、直角と斜辺、無作為と結果のばらつきを各説明・問題・図で揃える。

## 10. Rollback / fallback
旧版への単純巻戻しを行わない。版7読書きと全accepted教材を保持したまま中3入口を隠し、保存投影から中3を除かない。未公開段階の不具合は機能branchで修正。random失敗時も固定例を閲覧可能にし、無作為に得た結果とは表示しない。

## 11. Open questions
達成率の文言、サポーター数値、追加ゲーム、次の教材拡張は既定で進めQUESTIONS.mdへ記録。運営者の採用判断と実際の教室での確認は未実施と明記する。

## 12. Human approval needed
既存の実装・push・merge・公開依頼の範囲で進める。権限変更、force push、実在児童データは扱わない。review.publication=preview、humanApproval=nullを維持。独立技術・数学検査を人の教材採用確認と呼ばない。
