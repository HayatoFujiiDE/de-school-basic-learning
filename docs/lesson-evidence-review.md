## 制作途中に検出・切り分けた表示問題

- **動画の重なり（確認済み）**: 角度の270°と式、面積の2cmと切り取り片が重なった。Hiragino Sans の実 bbox で、前者は幅0.82364×高さ0.21260、後者は0.47539×0.29550の交差を再現した。1280×720では約74.1×19.1px、42.8×26.6pxに相当する。
- **フォント候補を除外**: 指定された Hiragino Sans は実在し、Arial に替えても両交差が再現した。フォント欠落だけでは説明できない。
- **抽出タイミング候補を分離**: 旧 MP4 の面積18秒・角度20秒の静止場面でも重なった。一方、正方形動画の文字混合は5秒間隔の抽出が式の Transform 途中を拾ったもので、26秒の静止場面では解消した。
- **計器の陽性対照**: 実在する交差を検出し、式を下へ1単位ずらした比較では交差高さ0になった。常に交差と判定する検査器ではない。
- **根因**: 図・寸法・式を独立の絶対座標へ置き、移動後を含む占有領域を分離していなかった。制作担当は領域検査と相対配置へ変更し、式の字形変形をフェード切替へ変更した。修正後の実画像で解消を確認した。
- **分数の仕切り**: 残る3枚の輪郭を塗りと同じ緑にすると仕切りが消えていた。仕切りを別色で保つ修正を確認した。
- **操作SVGの移動途中**: 割合の7.5枚幅に8枚と丸めて表示する状態を検出。途中の枚数を表示しない修正を確認した。途中の未完成図に最終値を現在値として見せない表現も確認した。
- **操作SVGの文字配置**: 270°と旧 footer の実ブラウザ bbox は交差した。footer を下へ分離して解消。小数の「取り分けた2.46」と式は画像上の接近を候補としたが、担当の実 bbox は横に約7.21の隙間があり、旧状態でも交差しなかった。重なりという根因の証拠には採用せず、余白改善として区別する。

以上はローカル制作途中で見つけた候補 incident の範囲。公開後の障害や利用者への被害を示す証拠はない。仕様どおりの Transform と配色、計測ミス、相関だけの断定、呼出側、検査器、その他を分け、持続する衝突は実画像＋二つのフォントでの bbox 再現に基づいて判断した。
