# 小学5年生の追加計画

## 目的と現在地
2026-11-04の依頼により第5学年を追加する。基準点はmain 39de594、fetch後の乖離0/0。第4学年20単元145問、既存の操作図20・動く解説8・動画4を保つ。新しい単元ごとに説明、練習、問いかけ、関心別の例、操作図を用意する。教材の正確さと実際の操作を独立に確認する。実児童の情報、外部AI接続、運用環境への配信は含まない。

## 比較した構成
1. 全学年をunits.jsへ統合して全面改訂する。構造は単純だが既存教材の独立確認hashと記録移行の影響が広い。
2. 学年ごとの静的JSを順序付きで読み込む。第4学年のファイルは不変とし、第5学年を追加する。共通core・画面・操作部品を使う。
3. 学年ごとにアプリ全体を複製する。隔離は強いが修正の二重管理・学年間の移動と記録保存が複雑になる。

2を選ぶ。動的読み込み、module、fetch、追加ランタイム依存は導入しない。学年ボタンで一覧を絞り、coreは常に両学年の教材と記録を持つ。直接単元へ入った場合も学年を合わせる。

## 依存と変更点
公式Excel・算数解説 → 第5学年の対応表 → 原稿とclaims → 操作図・動く解説 → 独立内容確認 → 全画面検査。内容制作と共通UI実装は契約確定後に並列化する。図の数値例はclaimsと照合する。

- units.jsと第4学年の素材は変更しない。新しいunits-grade5.jsを追加する。
- coreの厳格なコード検査を第4・第5学年へ拡張する。学年とcodeの一致を確認する。
- 教材版3へ更新。版2の第4学年の記録だけを移す。既存教材のバイト同一性を機械検査し、他の旧版や将来版を無条件に移さない。
- 正誤は保存値を信じず再計算。学年選択は記録全体を削らない。自由入力は永続保存しない。
- 既存の描画器に単元別draw拡張を追加する。登録済み単元、状態の範囲、操作対象の一致という境界は保つ。
- 動く解説は選んだ概念に絞る。再生停止・段階送り・戻る・動きを減らす設定を共通部品で扱う。

## 合格条件
独立担当が全解答・全claims・公式コード対応・図の数と単位を確認する。誤答や内容変更の検出を正例で試す。4年の元データhashと全既存検査を保持する。

実ブラウザfile://、1440/1024/390、小学生・中学生の両表示で全単元・各画面を検査する。全問題、ゲーム、バディ自己確認、学年往復、保存と再読込、途中再開、キーボード、停止と減速設定、外部通信なしを確認する。機械検査だけでなく各単元の図と説明の見え方も点検し、発見した課題を修正して再検査する。

## 復旧と残る判断
独立ブランチで作業し、検証した機能単位でcommitする。導入前へ戻す場合は対象commitをrevertする。旧アプリへの戻しでは版3の記録は互換でないため、版3のブラウザ記録を消さず保管し、誤った自動変換をしない。
学年の次の拡張順、実児童への配信と運営の内容承認は別途判断とする。公開GitHubのソースは実データを含めず、公開前にdiff・履歴・機密情報の混入を検査する。

| 作業 | 依存 | 並列 | 検査 |
| --- | --- | --- | --- |
| 第5学年の抽出・構成 | 公式資料 | 可 | 全leaf対応 |
| 共通core・学年UI | 契約 | 可 | 移行・往復・再読込 |
| 原稿・練習・claims | 単元構成 | 可 | 独立全件確認 |
| 操作図・解説 | 構成・数値契約 | 可 | 全状態・境界・可視図 |
| 統合総点検と改良 | 上記 | 不可 | 全検査・目視・再検査 |

## 独立設計レビューへの反映
- 第4学年のファイルhashに加え、追加script読込後の第4学年unit全体と元sources/categoriesが元のままであることを独立fixtureで照合する。
- 学年別の期待code集合を一次資料・凍結manifestとして持ち、読込・受理・表示の三段階を完全一致で比較する。読込漏れの陽性対照を入れる。
- 第5学年の全問は別担当が再計算した期待値を使う。制作側による期待値の自動更新は禁止する。分数は約分した答えの選択、指定した分母の分子の数値回答等を組み合わせ、無理な文字列入力へ拡張しない。
- 進捗は実coreで2→3、再読込、学年往復、保存拒否、破損値、mode/interest/resume/buddyを検査する。
- 対応表・claims一覧・解答監査を実体と照合する。内容leafだけでなく内容の取扱い・数学的活動のカバレッジも点検する。
- 正常な最終図だけでなく操作の途中・最大最小、図内の重なり、文字・数・単位を点検し、失敗を検出できる正例を入れる。
