## 内容と照合記録

- `js/units.js`: 20単元、145問、ゲーム20問。各単元に小学生/中学生×短い/詳しい説明、関心別の入口2つ、4段階例題、つまずきの訂正、個別ヒント、バディの問い・追加問い・確認点・説明例を持つ。動く図の一般則もclaimsに含む。
- `coverage-map.json`: 元138行を20単元へ対応付ける。127行が内容・目標・用語・指導上の扱いとして対応し、11行は学年や領域など構造上の見出し。思考・説明・日常での活用は文脈例とバディにも対応する。単なるコードの登録を、その技能の全習得を証明するものとは扱わない。
- `claims-index.json`: 教材の表示箇所から365の主張への対応。説明、入口、設問と正答・解説・ヒント、バディ、例題、誤り例と訂正、動く図を含む。意図的な誤答例は「誤った考え」と明示して訂正と一体の主張にする。
- `answer-audit.json`: 全83数値解答を問題文から別に立てた式で有理数として再計算した記録。演算は `+ - * / % floor ceil` の許可リストのみ。選択式・並べ替えの意味の正しさは独立の根拠確認に委ね、数値検査で検証したとは扱わない。
- 全単元の `review.evidence` は制作時 `pending`。独立検証で合意された同じ内容に対してのみ統合担当が `verified` にする。`publication` は `preview`、`humanApproval` はnull。独立検証は公開の人間承認を代替しない。

## 抽出の再現

プロジェクト直下で次を実行する。ネットワークと追加Pythonパッケージは不要。

```sh
python3 tools/extract-curriculum.py
node --check js/units.js
```

抽出器は固定SHA-256を先に検査し、138行・コード重複・形式を検証する。原本が更新された場合は、自動的に新しい内容へ切り替えず、出典と対応を再確認する。

## 範囲と限界

第4学年の4領域と、そろばん、3桁区切り、a/ha、複数系列と組合せグラフ、落ち重なり、整数を割って小数になる例を含めた初期教材。台形は公式解説の分類に沿い「平行な対辺が1組だけ」とする。公式解説には「一組の辺が平行」の表現もあるため、教材内で定義を明示した。

図や練習・自己確認は、実物での作図、分度器による測定、紙の展開図の組立て、そろばんの実操作、他者との説明活動すべてを置き換えない。画面のバディは固定の問いと自己確認であり、自然言語の正誤をAIが判定したという扱いにはしない。取り組みの記録から児童の能力全般を断定しない。
