## 開く

`index.html` をブラウザで開きます。ビルドもサーバーも不要です。このMacでは次のコマンドで開けます。

```sh
open /Users/hayatofujii/Coding/DESystem/Basic-Learning/index.html
```

アプリは素のHTML/CSS/JS、ES2017以内、非moduleです。すべての教材をJSに同梱し、fetch・API通信を行いません。外部依存は `css/tokens.css` のGoogle Fonts 1行のみで、オフラインではシステムフォントで動作します。Nodeや検証ライブラリは教材の利用には不要です。

制作プレビューとして納品します。数学とコードの独立検証、運営による公開承認は区別しています。公開承認は未実施で、全単元の `humanApproval` は `null` です。

## 達成率

```text
単元の達成率 = floor(80 × 正答した問題数 / 練習問題数
                    + 20 × 説明を確認した問いかけ数 / 問いかけ数)
```

問題ごとの**最新の有効な回答**を使います。答え直して誤答になればその問題分は下がります。未回答は0、空欄や無効な入力は前の有効な回答を上書きしません。練習が全部正答なら80%、説明もすべて確認すると100%。小さなクイズ、操作図、図解内の予想は何度でも試せ、達成率には加えません。本人の説明確認は取り消せます。

「説明できた」は、問いかけの確認項目を読んだ**本人による確認**です。この版のバディはあらかじめ用意した問い・返答で対話します。自由文の意味をAIで判定する機能、オンラインのバディへの接続はありません。画面でも明示しています。

## 保存とプライバシー

ブラウザの `localStorage` の `des.basic-learning.v1` 一つに、表示モード・関心・単元の続き・問題ごとの回答と正誤・説明の自己確認を保存します。未知のフィールドは保存前に落とし、正誤は読込時に再計算します。バディに書いた文章はメモリ上だけに置き、再読込・ページを閉じると消えます。ファクトリーや外部へ送信しません。

保存を拒否された環境では画面に通知し、そのページを開いている間はメモリで継続できます。壊れた保存値は安全な初期状態に戻します。教材の版 `BL.data.version` を変えると過去の達成記録は引き継ぎません。

`file://` における保存の扱いはブラウザや設定によって異なり、ファイルの移動でも記録を引き継げない場合があります。[MDN localStorage](https://developer.mozilla.org/en-US/docs/Web/API/Window/localStorage) を参照してください。この納品ではインストール済みChromeのfile URLで検証しています。

## 検証

```sh
cd /Users/hayatofujii/Coding/DESystem/Basic-Learning
sh tools/check.sh
```

この環境には検証専用Acorn 8.15.0を用意済みです。PlaywrightはCodexの同梱1.62.1、ブラウザはインストール済みChromeを使います。別環境ではNodeと、検証用のAcorn 8.15.0／Playwrightを用意してください。`tools/dependencies.cjs` はローカルnode_modules、`BASIC_LEARNING_CHECK_MODULES`、Codex同梱の順に解決します。ブラウザ実体は `BASIC_LEARNING_CHROME` で指定できます。検証用依存はアプリから読み込みません。

機械検査はES2017構文・素材構造・公式コード対応・禁止語・正答/進捗/保存ガード・操作図の独立した数式検査を含みます。ブラウザでは1440/1024/390px、両表示、全単元の画面、全145問の回答、バディの確認/取消、関心切替、例題手順、保存不能/破損、休止再開、HTML注入耐性を確認します。通信を遮断した状態で実行し、空のDOMを合格にしません。禁止語・横はみ出し・JSエラーの検出器には、検出できる条件を意図的に与えるpositive probeを入れています。

`output/content-check.json` と `output/browser-check.json` に直近の実行結果、`output/playwright/` に画面画像が残ります。出力と依存ディレクトリはGitに含めません。検証は `CHECK_RESULT=PASS` と終了値0が両方必要です。

今後の判断は `QUESTIONS.md` にまとめています。

追加検査: `node tools/check-lessons-math.cjs`（独立した図の数理検査）、`node tools/check-media.cjs`（4動画のhash・全フレームdecode）、`node tools/check-lessons.cjs`（3画面幅・両表示・全段階・停止/再開・動画の実再生）。これらも `sh tools/check.sh` に含みます。動画検査には既存の `ffmpeg` / `ffprobe` を使います。
