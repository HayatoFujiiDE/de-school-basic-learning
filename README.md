# 基礎学習 — 小学4・5年生の算数

DE-SCHOOLの基礎学習教材。第4学年に加え、2026-11-04の依頼により第5学年を追加しました。クイズ・操作できる図・説明・練習・自分の言葉での確認を組み合わせます。

## 開く

`index.html`をブラウザで開き、画面上部の「小学4年生」「小学5年生」で切り替えます。Macでは、このフォルダで `open index.html` を実行できます。5年生の一覧は `index.html#list/5` です。

ビルド・サーバー不要のHTML/CSS/JSです。ES2017以内、非module、fetch・API通信なし。教材と画像・動画は同梱し、外部依存はGoogle Fontsの1行だけです。オフラインではシステムフォントを使います。検証用のNode・Python・Manimは利用時に不要です。

全教材は独自制作です。GitHubのソース公開と、運営による子ども向け配信承認は区別します。この版は制作プレビューで、`humanApproval` は全単元 `null` です。自動検査・独立した数学確認は実施していますが、実際の授業での利用検証や運営による内容承認を代わりに済ませたとは扱いません。

5年生の動く解説は、小数のかけ算・わり算、異分母分数の足し算、三角形の面積、割合、平均です。分数と平均には19.5秒／20.1秒の動画もあります。「予想する→途中を動かして見る→前に戻る→自分で図を変える」を選べます。自動再生せず、停止・段階送り・文字による全文表示・OSの動きを減らす設定に対応します。予想と操作図は達成率に含めません。

公式コードとの対応は学習内容の関連を示すもので、画面操作だけで年間の力をすべて確認したとは判定しません。紙に図を描く、実物を測る・組み立てる、人に説明する活動も併せて扱います。

## 達成率と保存

`floor(80 × 最新の正答数 / 練習問題数 + 20 × 本人が説明確認した問い数 / バディの問い数)`

全問正答で80%、説明確認もすべて済むと100%。誤答への変更や説明確認の取り消しも反映します。小数誤差で全完了が99%にならないよう、実装は整数の比で計算します。

保存先はブラウザの `localStorage` の `des.basic-learning.v1` だけです。学年、表示モード、関心、各問題の最新回答、自己確認、再開先を保存し、保存された正誤は再計算します。バディに入力した文章はそのページのメモリ内だけに置き、再読込・終了で消えます。外部送信・録音・追跡はありません。

今回の教材版は3。版2からは、内容が完全に同じ第4学年の記録だけを引き継ぎます。5年生の偽装記録や他の旧版は移行しません。学年を切り替えても、保存処理は両学年を保持します。将来の教材変更では新たな内容照合と移行判断が必要です。

保存を拒否された環境では通知し、そのページを開いている間はメモリで継続できます。破損した保存値は安全な初期状態に戻します。`file://` の保存はブラウザ・設定・ファイルの移動によって変わり得ます（[MDN localStorage](https://developer.mozilla.org/en-US/docs/Web/API/Window/localStorage)）。この版はMacのChromeで検証しています。

## 根拠と差し替え

[文部科学省の公式ページ](https://www.mext.go.jp/a_menu/other/data_00001.htm)で公開されているExcel 82V12を使い、第4・第5学年の算数を抽出しました。コードは16文字の文字列で、英字を含む場合も数値へ変換しません。[算数編解説](https://www.mext.go.jp/content/20211102-mxt_kyoiku02-100002607_04.pdf)も確認しています。[eboardの一覧](https://www.eboard.jp/list/7/)は構成・並び方の参考に限り、文章・問題・画像・動画は転載していません。

- `js/units.js`：第4学年。既存公開版からバイトを変更していません。
- `js/units-grade5.js`：第5学年と追加メタ情報。既存の単元・出典・カテゴリを変更せず追加します。
- `sources/grade4-math-codes.json`・`grade5-math-codes.json`：公式の行番号・コード・本文。
- `sources/coverage-map.json`・`grade5-coverage-map.json`：対応する単元と適用範囲。
- `sources/claims-index.json`・`grade5-claims-index.json`：本文・問題・図と主張の対応。
- `sources/grade5-content-review.json`・`grade5-visual-review.json`・`media-grade5-manifest.json`：独立確認と素材hash。
- `docs/content-contract.md`：ファクトリーからの素材差し替え契約。
- `docs/grade5-evidence-review.md`・`grade5-visual-design.md`：確認方法と限界。
- `docs/verification-grade5.md`：総点検と修正後の実出力。

各単元は `claims` と `adapt-rules` を持ちます。未確認の素材は読み込み時に除外します。静的な構造検査だけで自由文の真偽を証明するものではなく、内容更新のたびに別担当による確認を必須にします。

```sh
python3 tools/extract-curriculum.py --grade 4 --output /tmp/basic-learning-grade4-codes.json
python3 tools/extract-curriculum.py --grade 5 --output /tmp/basic-learning-grade5-codes.json
```

## 検証

```sh
sh tools/check.sh
```

検証用にNode、Python、Acorn、Playwright、Chrome、ffmpeg/ffprobeを使います。教材本体からは読み込みません。`tools/dependencies.cjs` はローカルnode_modules、`BASIC_LEARNING_CHECK_MODULES`、Codex同梱環境の順で解決し、ブラウザは `BASIC_LEARNING_CHROME` で指定できます。この環境ではAcorn 8.15.0、Playwright 1.62.1を使用しました。

検査は、全解答の独立再計算、主張・公式コード・対応表、元の4年生の不変性、記録移行、禁止語、ES2017、描画途中の数量と面積、動画の全デコード、実Chromeの全画面・全問・保存と再開を含みます。幅1440/1024/390、小学生／中学生の両表示を対象にします。誤った答え、内容改変、教材未読込、数の欠落、重なる経路、描画前の学年を検出する対照検査も含みます。

素材を再制作すると独立確認hashを更新する必要があります。動画用Skill・既存Manim環境の安全確認は `docs/skill-safety-review.md` に記録しています。検証ログと画像は `output/` に生成し、公開リポジトリには含めません。
