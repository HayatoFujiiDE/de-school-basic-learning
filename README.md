# 基礎学習 — 小学4・5・6年生の算数／中学1年生の数学

DE-SCHOOLの基礎学習教材。小学4・5・6年生に加え、中学1年生の数学を追加しました。クイズ・操作できる図・説明・練習・自分の言葉での確認を組み合わせます。

## 開く

`index.html`をブラウザで開き、画面上部の「小学4年生」「小学5年生」「小学6年生」「中学1年生」で切り替えます。Macでは、このフォルダで `open index.html` を実行できます。中学1年生の一覧は `index.html#list/7` です。内部の学年値7は中学1年生を表し、文科省コードの学年値とは区別します。

ビルド・サーバー不要のHTML/CSS/JSです。ES2017以内、非module、fetch・API通信なし。教材と画像・動画は同梱し、外部依存はGoogle Fontsの1行だけです。オフラインではシステムフォントを使います。検証用のNode・Python・Manimは利用時に不要です。

全教材は独自制作です。GitHubのソース公開と、運営による子ども向け配信承認は区別します。この版は制作プレビューで、`humanApproval` は全単元 `null` です。自動検査・独立した数学確認は実施していますが、実際の授業での利用検証や運営による内容承認を代わりに済ませたとは扱いません。

5年生の動く解説は、小数のかけ算・わり算、異分母分数の足し算、三角形の面積、割合、平均です。分数と平均には19.5秒／20.1秒の動画もあります。「予想する→途中を動かして見る→前に戻る→自分で図を変える」を選べます。自動再生せず、停止・段階送り・文字による全文表示・OSの動きを減らす設定に対応します。予想と操作図は達成率に含めません。

6年生の動く解説は、分数のかけ算・わり算、線対称、比の利用、円の面積、反比例です。分数のかけ算と比の利用には各19秒の動画があります。22単元すべてに操作図を用意し、分割した区画、対応点、比のまとまり、一定の面積、データの分布、場合の数を自分で動かして確かめられます。

中学1年生は、正負の数・文字と式・方程式、比例・反比例、平面図形・空間図形、データ・多数回の試行の順です。38単元すべてで、数直線、表、グラフ、コンパスによる作図、展開図、度数分布などを操作できます。8本の動く解説は、負の数の減法・乗法、方程式、比例・反比例、垂直二等分線、扇形、多数回の試行。減法20秒と方程式23秒の動画も同梱しています。

公式コードとの対応は学習内容の関連を示すもので、画面操作だけで年間の力をすべて確認したとは判定しません。紙に図を描く、実物を測る・組み立てる、人に説明する活動も併せて扱います。

## 達成率と保存

`floor(80 × 最新の正答数 / 練習問題数 + 20 × 本人が説明確認した問い数 / バディの問い数)`

全問正答で80%、説明確認もすべて済むと100%。誤答への変更や説明確認の取り消しも反映します。小数誤差で全完了が99%にならないよう、実装は整数の比で計算します。

保存先はブラウザの `localStorage` の `des.basic-learning.v1` だけです。学年、表示モード、関心、各問題の最新回答、自己確認、再開先を保存し、保存された正誤は再計算します。バディに入力した文章はそのページのメモリ内だけに置き、再読込・終了で消えます。外部送信・録音・追跡はありません。

今回の教材版は5。版2からは小学4年生、版3からは小学4・5年生、版4からは小学4・5・6年生の同一内容の記録を引き継ぎます。元の3学年のデータファイルは変更していません。学年切替後も4学年分の回答と自己確認を保持します。未来の版・破損した記録・読込失敗・教材の一部欠落は、元の保存値を上書きしません。学年別ファイルや期待する104コードの登録が欠けると教材を開かず、未確認単元が混ざる場合は保存を止めます。

保存を止めた場合は、保存していないことと今回の回答が残らないことを画面に通知し、利用可能な教材はメモリ内で続けられます。破損値も消去せず保持します。復旧のため中学1年生の入口を隠す場合も、版5のcoreと104単元は残し、古い版へ戻して記録を消さない構成です。将来の教材変更では新たな内容照合と移行判断が必要です。

`file://` の保存はブラウザ・設定・ファイルの移動によって変わり得ます（[MDN localStorage](https://developer.mozilla.org/en-US/docs/Web/API/Window/localStorage)）。この版はMacのChromeで検証しています。

## 検証

```sh
sh tools/check.sh
```

検証用にNode、Python、Acorn、Playwright、Chrome、ffmpeg/ffprobeを使います。教材本体からは読み込みません。`tools/dependencies.cjs` はローカルnode_modules、`BASIC_LEARNING_CHECK_MODULES`、Codex同梱環境の順で解決し、ブラウザは `BASIC_LEARNING_CHROME` で指定できます。この環境ではAcorn 8.15.0、Playwright 1.62.1を使用しました。

検査は、全解答の独立再計算、主張・公式コード・対応表、元の小学4・5・6年生の不変性、記録移行、禁止語、ES2017、描画途中の数量と面積・区画境界の視認性、動画の全デコード、実Chromeの全画面・全問・保存と再開を含みます。幅1440/1024/390、小学生／中学生の両表示を対象にします。誤った答え、内容改変、教材未読込、数の欠落、重なる経路、描画前の学年を検出する対照検査も含みます。

素材を再制作すると独立確認hashを更新する必要があります。動画用Skill・既存Manim環境の安全確認は `docs/skill-safety-review.md` に記録しています。検証ログと画像は `output/` に生成し、公開リポジトリには含めません。
